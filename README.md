# Princípios SOLID em Dart

## Sobre o projeto

Este projeto tem como objetivo apresentar os cinco princípios SOLID e demonstrar sua aplicação na linguagem Dart.

Os exemplos mostram a diferença entre códigos que não seguem os princípios SOLID e códigos que aplicam esses conceitos, destacando a importância de escrever códigos mais organizados, simples, reutilizáveis e fáceis de manter.

## Organização do projeto

- **SemAplicacao/**: contém exemplos de códigos que não aplicam os princípios SOLID.
- **ComAplicacao/**: contém exemplos de códigos que aplicam os princípios SOLID.

## Princípios SOLID

1. **SRP (Single Responsibility Principle):** Princípio da Responsabilidade Única.
2. **OCP (Open/Closed Principle):** Princípio Aberto/Fechado.
3. **LSP (Liskov Substitution Principle):** Princípio da Substituição de Liskov.
4. **ISP (Interface Segregation Principle):** Princípio da Segregação de Interfaces.
5. **DIP (Dependency Inversion Principle):** Princípio da Inversão de Dependência.

## Tecnologias utilizadas

- Linguagem Dart.
- Visual Studio Code.
- Git e GitHub.

## Como executar

Para executar um exemplo, utilize o terminal na pasta principal do projeto:

```bash
dart run ComAplicacao/SingleResponsibilityPrinciple.dart
```
